## 五、图表规划

### 5.1 雷达图（四维模型可视化）

```
用途：展示用户在四维模型三个维度上的得分 vs 两个基准案例

类型：ECharts 雷达图（radar）
数据系列：3条（用户 / 克拉玛依 / 伊吾）
维度轴：资源转化、公共支撑、生态构建
颜色：用户=橙 #F07A00，克拉玛依=蓝 #005FC8，伊吾=绿 #00A07A

交互：鼠标悬停显示具体数值
```

### 5.2 柱状图（参数对比）

```
用途：8个参数逐一对比用户 vs 两个基准案例

类型：ECharts 分组柱状图（bar）
数据系列：3组（用户 / 克拉玛依 / 伊吾）
X轴：8个参数名称
颜色：同上

交互：点击柱体可查看具体数值
标注：每个柱体上方标具体数字
```

### 5.3 匹配度条形图

```
用途：直观展示两种路径的匹配百分比

类型：纯CSS双色进度条
左半：生态构建型（蓝渐变）
右半：资源转化型（绿渐变）
中间：百分比数字标注
```

## 六、关键交互细节

### 6.1 参数输入的即时反馈

```
每个输入框变化时：
  1. 右侧数值标签实时更新
  2. 表单底色轻微闪烁（.2s过渡）
  3. 输入有效性实时校验（范围外显示红色提示）

优化：不用点按钮，参数变化→结果自动重算（debounce 500ms）
```

### 6.2 "载入参考"交互

```
点击"载入参考"→ 弹出下拉菜单
  ├── 载入克拉玛依数据（自动填入并分析）
  └── 载入伊吾数据（自动填入并分析）

选中后：
  1. 所有输入框瞬间填入对应数据（动画过渡）
  2. 结果区自动更新
  3. 输入框高亮显示"已加载参考数据"
```

### 6.3 结果区动画

```
分析完成后：
  1. 路径标签：从上方滑入（.3s）
  2. 匹配度条：从左到右填充（.5s）
  3. 雷达图：ECharts自带入场动画
  4. 建议列表：逐条淡入（每条间隔.1s）
```

### 6.4 可折叠参考案例

```
结果区底部：
  "📖 查看克拉玛依 vs 伊吾完整数据对比"
  点击展开一个带格式的对比表格
  包含：行政层级/财政/企业/电价/PUE/算力等15项对比
  每项数据旁边标注来源等级[A/B/C]
```

## 七、数据来源标注方式

```
所有显示的数据旁标注可信度等级：

  "一般公共预算收入：122.2亿元 [A]"
  "智能算力规模：17,000P [A]"  
  "入驻企业：185家 [B]"
  "应用场景：7类 [C]"

图例：
  [A] = 官方统计数据
  [B] = 政府公告/工作报告
  [C] = 归纳推断值（基于公开资料）
```

## 八、手机端特殊处理

```
输入优化：
  - 数字键盘（inputmode="decimal"）
  - 输入框高度加大（48px+）方便触屏
  - 滑块替代数字输入（可选模式）

布局调整：
  - 输入区和结果区改为上下排列
  - 结果区在输入区下方
  - 图表缩小但保持可读性
  - 操作按钮加大（min 44px touch target）

性能：
  - ECharts配置responsive自适应
  - 禁用动画（移动端）
```

## 九、技术实现方案

```
技术栈：纯HTML + CSS + JS + ECharts
文件结构：
  index.html     → 主页面（含HTML结构 + CSS + JS）
  （所有代码在一个文件中方便修改）

外部依赖：
  ECharts CDN → https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js
  （百度产品，中国可访问）

核心算法：TOPSIS（内嵌在JS中）
数据：所有数据硬编码在JS中（data.js结构）

无需：
  × 无npm/node
  × 无数据库
  × 无后端
  × 无构建步骤
  × 无框架
```
