# 绿算治策 · 网站使用说明

> 用途：帮助用户理解网站的使用方法、功能流程和结果解读
> 目标用户：地方政府工作人员、参赛评委、对绿色算力规划感兴趣的研究者

---

## 一、网站是什么

**绿算治策**是一个绿色算力产业治理决策辅助工具。

它的作用是：**你输入你所在地区的8项基本数据，它帮你判断最适合走哪种发展路径，并告诉你应该优先做什么。**

它基于两个真实案例的研究成果：
- **克拉玛依**（生态构建型路径）
- **伊吾**（资源转化型路径）

你不需要懂算法，也不需要看原始数据，只需要填数字，网站自动出结果。

---

## 二、使用流程

```
第一步：打开网站
      ↓
第二步：输入地区名称，然后填写8项参数
      ↓
第三步：点击「生成产业评估报告」
      ↓
第四步：查看路径判定、四维评分、维度可视化
      ↓
第五步：查看第4部分「发展建议」和风险提示
      ↓
第六步（可选）：点击「导出报告」选择 Word 或 PDF 格式下载
      ↓
第七步（可选）：展开完整对比表查看参数明细
```

**第一步：打开网站**
在浏览器打开绿算治策页面即可，无需注册或登录。

**第二步：填写8项参数**
在左侧输入区依次填写8个数字，每个输入框右侧有单位提示（亿元、家、%等）和填写说明。如果某些数据不确定，可以参考"载入参考"功能看两个案例的数据是多少。

**第三步：点击"开始分析"**
填写完所有参数后，点击蓝色"开始分析"按钮。

**第四步：查看结果**
右侧结果区会显示：
1. 判定你适合的路径类型
2. 与两种路径的匹配度百分比
3. 你的各项参数与参考案例的对比
4. 针对性发展建议
5. 风险提示

## 三、页面功能分区

### 3.1 顶部导航栏

```
左侧：项目名称"绿算治策"
右侧：参赛标识"中国国际大学生创新大赛（2026）"
```

### 3.2 左侧：参数输入区

包含8个数字输入框，每个输入框对应一个维度。

**每个输入框包含：**
- 参数名称（如"行政层级指数"）
- 当前输入值（实时显示）
- 单位（如"亿元"、"家"、"元/度"）
- 快捷参考提示（最小值、最大值）

**关于"载入参考"按钮：**
- "载入参考：克拉玛依" → 一键填入克拉玛依的真实数据
- "载入参考：伊吾" → 一键填入伊吾的真实数据
- 这两个按钮的作用是**给用户参考**，看看真实的城市数据是多少
- 点击后会自动填入数据并自动分析

### 3.3 右侧：结果展示区

默认显示引导文案，点击"开始分析"后显示分析结果。

**结果包含：**
1. **路径标签**：生态构建型 / 资源转化型 / 混合型
2. **路径说明**：用一句话解释这条路径是什么
3. **相似度进度条**：两条彩条，显示你和克拉玛依的相似度、和伊吾的相似度
4. **参数对比表**：你的8项参数 vs 两个参考案例
5. **发展建议**：针对你匹配的路径给出的具体行动建议
6. **风险提示**：走这条路需要注意什么
7. **参考案例折叠区**：点开可查看克拉玛依和伊吾的详细数据对比

## 四、结果解读指南

### 4.1 看懂路径判定

```
结果示例：生态构建型（以克拉玛依为参考）

是什么意思：
  你的地区条件与克拉玛依更接近
  适合走"政府主导+全链条生态培育"的路子
  建议重点做：产业基金、场景开放、政策工具箱、人才引进
```

### 4.2 看懂相似度进度条

```
示例：
  🌳 生态构建型 73%  │██████████████████│  ⚡ 资源转化型 27%

怎么理解：
  73% → 你的数据和克拉玛依有73%的相似度
  27% → 你的数据和伊吾有27%的相似度
  结论：你更适合走生态构建型路径
```

### 4.3 看懂参数对比

```
参数对比表（示例）：
  ┌─────────────────────┬──────┬──────────┬─────────┐
  │      维度          │ 你的值 │ 克拉玛依 │  伊吾   │
  ├─────────────────────┼──────┼──────────┼─────────┤
  │ 年可支配财政(亿元)  │  80  │   120    │   10    │
  └─────────────────────┴──────┴──────────┴─────────┘

怎么理解：
  你的财政收入80亿，低于克拉玛依的120亿，但远高于伊吾的10亿
  说明：你虽然不如克拉玛依有钱，但比伊吾好得多 → 可能走介于两者之间的路线
```

### 4.4 看懂建议和风险

```
发展建议（示例）：
  ✅ 设立产业引导基金，构建多层次资金支持体系
  ✅ 发放算力券/运营补贴，降低中小企业用算门槛

风险提示（示例）：
  ⚠️ 防范财政补贴依赖，设定退出机制和补贴递减路径
  ⚠️ 防止产业地产化，避免为招商而招商导致空置

怎么理解：
  建议 → 你应该优先做的具体事情
  风险 → 做这些事情的时候要注意什么坑
```

## 五、常见问题

### Q1：有些数据我不知道怎么填怎么办？

A：可以先用"载入参考"功能看克拉玛依和伊吾的数据，大致判断你所在地区处于什么水平。比如你的地区是县级、财政较弱，可以参照伊吾的数据填。

### Q2：数据填错了影响大吗？

A：这个模型是基于趋势判断，不是精确计算。即使个别数据有偏差，整体方向不会变。建议尽量填真实数据，结果更准确。

### Q3：我的判读结果是"混合型"是什么意思？

A：说明你的条件介于两种路径之间，没有特别明显的倾向。可以看看自己哪个维度的数据更有优势，先从这个维度突破。

### Q4：这个工具能直接给出规划方案吗？

A：不能。这个工具提供的是**方向性建议**，具体的产业规划需要结合当地实际情况进一步研究。

### Q5：数据来源可靠吗？

A：所有数据都标注了可信度等级：
- [A] 官方统计数据
- [B] 政府公告/工作报告
- [C] 行业报告/企业公告
- [D] 媒体报道/估算值

可以在结果下方展开"参考案例"查看完整数据来源。

## 六、技术说明（供参考）

- 本工具为纯前端静态网页，无需后端服务
- 所有计算在用户浏览器中完成，数据不上传
- 算法：加权欧氏距离相似度匹配
- 输入限制：仅接受数字，会自动校验范围
- 兼容性：支持主流浏览器（Chrome/Edge/Firefox/Safari）
